# QADAM — Ta’lim markazi

Ko‘k va apelsin rangdagi, o‘zbek tilidagi o‘quv markazi sinov sayti.

GitHub Pages uchun React, TypeScript, Vite va Tailwind CSS bilan tayyorlangan.

## Ishga tushirish

Node.js 22.13 yoki yangiroq versiya va pnpm 11.19.0 kerak.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm preview
```

Sayt yo‘li: `/qadam/`. Uni o‘zgartirganda `vite.config.ts` va `index.html` ichidagi sayt manzillarini ham yangilang.

## Muhim: sinov versiyasi

- Kurslar, aloqa ma’lumotlari, statistikalar va fikrlar namuna sifatida berilgan.
- Ariza shakli ma’lumot yubormaydi va saqlamaydi; faqat tasdiqlash ko‘rinishini ko‘rsatadi.
- Video tugmasiga hali video ulanmagan.
- Haqiqiy ishga tushirishdan oldin ma’lumotlar va ariza jarayonini sozlash kerak.
